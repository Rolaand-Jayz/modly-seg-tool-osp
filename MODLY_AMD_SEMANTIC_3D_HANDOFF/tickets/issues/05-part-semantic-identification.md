# 05 — Open-vocabulary part semantic identification

**What to build:** Take topology-bound part segments and attach replaceable open-vocabulary semantic assertions through `Identify Part Semantics`, using source observations and/or rendered views while preserving unknown/ambiguous results instead of forcing every segment into a label.

**Blocked by:** 01 — Structured Asset headless round-trip; 02 — AMD Runtime proof through Modly; 04 — Native-3D part segmentation on 16 GB AMD.

**Owner decisions (2026-09-26):** Decider uses four independent one-image calls and an equal-weight mean of the ten-way A–J probabilities; each view uses the frozen context sentence `A single view of the same topology-bound part; other views are evaluated separately.` The approved calibration rule is the development-only I/J threshold search recorded below. Source-authored masks are label-blind semantic target inputs; GeoSAM2 segmentation quality remains independently evaluated, and genuine GeoSAM2 provenance/render artifacts are required.

**Current status:** in progress; contract, indexed fixture, truth-boundary evaluator, semantic workflow node, and Decider-only distribution registration seam are implemented. - [ ] Before model acceptance, the semantic fixture, expected/local ontology, coverage target, and correctness threshold are declared; the resolver then meets those thresholds for the accepted label subset and explicitly returns unknown/ambiguous for insufficient evidence rather than using free-form string similarity alone.
- [ ] Semantic labels are assertions, not part IDs, and changing a label does not mutate segmentation geometry.
- [ ] Labels support optional normalization to a controlled vocabulary while preserving the original open-vocabulary assertion and provenance.
- [ ] Every semantic assertion records evidence kind, confidence state/source, adapter/model provenance, observation/view references, and target topology revision.
- [ ] Conflicting candidate labels remain representable for later arbitration rather than being silently collapsed by raw confidence comparison across models.
- [ ] The adapter remains replaceable independently of the segmenter and does not require a specific geometry generator.
